# 同意轮盘（Consent Roulette）

一个离线、成年人自愿使用的 Android 日程挑战轮盘。它保留每日 V/W 双类别、X/Y 六面骰、累计分数、`≤ -5` 禁用、`≥ 10` 锁定以及每天一次记录的**机械规则**；不包含或复刻源图片中的露骨性任务内容。

## 功能

- 14–28 天周期或无尽模式，按设备本地日期控制当天可否记录。
- 选择 V 类别、随机生成不同 W 类别，并掷出 X/Y 骰子。
- 保存分数、开始日期和当天记录到 `SharedPreferences`，重启后自动恢复。
- 提供暂停/清除操作；所有数据仅存在设备本地。
- 六个非露骨占位类别：专注、运动、学习、睡眠、社交、放松。

## 构建

```bash
./gradlew test assembleDebug
```

生成的调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 安全说明

挑战项目应由成年人在充分、可撤回的同意下自行设定。应用不替代医疗、心理或人身安全建议；感到不适时应立即暂停并寻求支持。
